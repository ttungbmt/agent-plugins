# Docs and decisions

- `docs/adr/NNNN-<slug>.md` records why the project behaves the way it does. Read the relevant ADR before changing
  behaviour it covers; a hard-to-reverse decision gets a new ADR with the next number.
- `docs/design/` holds the intended behaviour of each command or module.
- `docs/research/<topic>.md` holds cited findings from primary sources that decisions build on.
